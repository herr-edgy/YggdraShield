# YggdraShield

A small Unreal Editor utility that guards your assets against being exported or migrated out of the project. It is also the sample plugin for my article *Extending tool menus in the editor via C++*.

> "Do not fear Helheim, for the titans can not export your assets."

## Install
1. Copy this folder into your project's `Plugins/` directory, so you have `Plugins/YggdraShield/YggdraShield.uplugin`.
2. Open the project (regenerate project files / rebuild when prompted).
3. Enable it under Edit > Plugins if needed, then restart the editor.

## Requirements
Unreal Engine 5.x.
